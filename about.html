Overview

The Community Help Desk Portal is a single-page Angular application designed to help users browse service announcements and support tickets. The system retrieves live data from a remote JSON API and presents it in an organized, user-friendly format.

Purpose

This portal demonstrates core Angular concepts including routing, shared services, observables, and pipes. It allows users to navigate between pages, view updates, search services, and interact with form-based content.
